# Role charters

One charter per role, independent of the seats that fill it.

| File | Charter |
| --- | --- |
| `incident-lead.md` | Own the incident: state impact, choose the next action, and refer work to the de |
| `triager.md` | Narrow the cause with evidence from dashboards and logs; report what you ruled o |
| `fixer.md` | Prepare the smallest safe fix for the cause triage named, and request approval b |
| `release-reviewer.md` | Check every proposed fix for blast radius and rollback before it is deployed |
