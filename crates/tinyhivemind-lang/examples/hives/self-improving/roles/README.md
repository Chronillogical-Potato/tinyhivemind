# Role charters

One charter per role, independent of the seats that fill it.

| File | Charter |
| --- | --- |
| `solver.md` | Answer the task exactly and show the computation that produced the answer |
| `critic.md` | Find the case the solver's answer gets wrong and cite the message that contains  |
| `editor.md` | Propose the smallest prompt or playbook edit that would have prevented the last  |
