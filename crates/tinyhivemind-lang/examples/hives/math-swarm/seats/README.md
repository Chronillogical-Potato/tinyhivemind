# Seat prompts

Fifty prompts, one per seat, named `<desk>-<NN>.md` for desk `conjecture`,
`compute`, `prove`, `verify` or `synthesis` and `NN` from `01` to `10`. Every
seat on a desk fills that desk's role; each prompt gives the seat a distinct
focus (a heuristic, a residue slice, a proof method, a check, or a weighing).

| Pattern | Role | Focus varies by |
| --- | --- | --- |
| `conjecture-NN.md` | conjecturer | guessing heuristic |
| `compute-NN.md` | computer | the modulus of its slice (3, 4, 5, 7, 8, 9, 11, 13, 16, 25) |
| `prove-NN.md` | prover | proof method |
| `verify-NN.md` | verifier | checking method |
| `synthesis-NN.md` | synthesizer | what it weighs |
