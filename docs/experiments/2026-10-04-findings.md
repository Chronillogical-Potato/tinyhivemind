# Findings, 2026-10-04

Rows appended by the agents that built the lab and the SWE hive.

## SWE lab build (`examples/lab/src/swe`): friction in core, driver and speech

Found while building the SWE hive, its single-agent baseline and the Harbor
wrapper. Each row is a friction, a bug or an improvement idea, with the place
it bit.

| Area | Finding | Impact | Suggestion |
| --- | --- | --- | --- |
| speech `tool_specs` | The five tools the hive offers (`post`, `broadcast`, `ask`, `complete_episode`, `read`) carry long descriptions that a host must render verbatim and resend on every model call. | A fixed per-call token cost on the arm being measured; it is paid per call, not per turn, so it grows with the number of seats and rounds. | Ship a compact description variant or a documented token estimate per spec, and a test that bounds total description size. |
| speech `interpret` | `interpret` accepts any served tool name, including `dm` and `ask_teammates`, even when the host did not offer them to the model. The host has to filter by offered names itself. | Easy to forget; a model that hallucinates an unoffered tool gets it accepted. | `interpret_among(name, args, allowed)` or an `allowed` field on the call arguments. |
| speech text rule | "Text outside a tool call reaches nobody." gpt-oss-class models often end a turn with plain text. | The lab promotes final text to an implicit `post`; without that a seat's whole turn vanishes. | Make the implicit-post policy a documented, core-owned option (`ImplicitPost::{Never, FinalText}`) so hosts agree. |
| speech `commit_utterance` | Needs `Roster`, `DeskSet`, `DispatchConversation` and `AsidePolicy` on every call, and `Roster`/`DeskSet` are borrowed views over slices the host must own. | The lab needs a `World` owner struct and a per-call rebuild just to append one row. | A `Desk`-level owned handle with `commit(speaker, utterance)`, built once. |
| speech `ask` | An `ask` opens an obligation the host must track until it is answered. No pure fold reports open asks per seat. | The lab did not offer `ask`-gated completion; a host that does would reimplement the bookkeeping. | A fold `open_asks(&rows) -> Vec<(asker, target)>` next to `pins`. |
| speech `broadcast` | Routing is "one TypeSafe Choice over the eligible team", which is a model call per broadcast. | An extra model call (tokens, latency) on the hive arm that the single arm never pays; hard to account for fairly. | A deterministic router fallback (role keywords or a response-threshold score) so the cost of semantic routing can be switched on and measured separately. The lab uses a keyword router (`hive::route_broadcast`). |
| `hive::step` | The deliberation fold is built on topics, bids and quorum. An open-ended task (fix a bug in a repo) has no topics, so the lab wrote its own mention-driven queue and used `hive::step` for nothing. | The "scheduled by core" claim does not hold for work-style rooms. | A pure `plan_round(queue, width)` plus "wake on mention, lead on quiet" policy in `driver`, so work-style rooms share the width bound by construction. |
| telemetry `TraceEvent` | `Round` and `Converged` require deliberation types (`Phase`, `Visibility`, `BidReason`, `TopicId`). The lab emits `Phase::Deliberate`, `Visibility::Full` and `TopicId("task")`. | The viewer shows deliberation labels for a coding run; the types lie slightly. | A host-neutral `Round { seats, label }`, or documented conventions for work rooms. |
| telemetry `TurnFinished` | Only `input_tokens` and `output_tokens`. gpt-oss reasoning tokens are folded into completion tokens and cached prompt tokens are invisible. | Cannot tell reasoning spend from answer spend, or see prompt-cache savings, which is exactly what a context-trimming intervention changes. | Optional `reasoning_tokens` and `cached_tokens` fields. |
| `Digester` port | The port assumes a model. A model fold adds tokens to the arm being measured. | The lab ships a zero-token extractive digester (`board/digester.rs`); a fair comparison needs one, and every host will write the same thing. | Ship an extractive `Digester` in core (pure, no model) and name it as the cost-neutral default. |
| `refold` / `read_pinboard` | They return futures although the lab's log and digester resolve immediately; the lab needs its own `block_on`. | Sync hosts carry an executor shim; the lab's `exec.rs` exists only for this. | Sync twins for ports that are ready, or a `block_on` in core behind a feature. |
| `SessionLog` | Core ships the port and no in-memory implementation, so every host and test rewrites `MemoryLog`. | Duplicate code; subtle ordering and cursor bugs recur. | A `testing` module with a reference in-memory log. |
| digest `ChannelHead` | `unfolded_chars` must be computed by the host, so the lab rescans every row on each `maintain`. | O(rows) per call; fine here, wrong for a long desk. | Have `ChannelDigest` carry the running char count of the rows it covers, or accept an iterator. |
| pins | `!pin` excerpts are 120 characters. A failing test name plus its command rarely fits, so the lead's pinned facts are clipped. | The pin is meant to carry the one fact nobody may lose. | Make `PIN_EXCERPT_CHARS` a `fold_pins` parameter, or show a short message whole. |
| concurrency | Seats share one container and one transcript lock, but nothing in core models a claim on a resource (a file). Implementer and tester can edit or run against the same files in the same round. | Round width bounds turns, not conflicts; wider rounds raise the chance of racing edits. | A stigmergy-style claim marker (`!claim path`) and a fold that reports contested paths, so a round can avoid scheduling two seats on the same one. |
| Harbor wrapper | The installed Harbor has no `--agent-import-path` flag; a custom agent is passed as `--agent module:Class` with the module on `PYTHONPATH`. | Older instructions for Harbor fail on this version. | Documented in `examples/lab/harbor/README.md`. |
| context cost | A hive seat restarts from a briefing every activation, so it loses its own bash history and re-reads files the previous activation had open. | Trims the repeated context but can cost extra tool calls; whether it nets out is the experiment. | Let a seat pin a short "working notes" row for itself (viewer-limited), measured as its own arm. |
